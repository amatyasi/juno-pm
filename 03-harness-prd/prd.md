## Problem & user

RocketShip PMs need this handled: You need to stress test (leadership) ideas with automated research from customer calls, support tickets, NPS records and enrich it with Twitter and Reddit context.. Juno does this inside limits a human set on purpose, and defends every call it makes.

## 01 Context · Data Requirements

**Required sources, and exclusions**

1. Support tickets from Jira
2. Customer connect transcripts from Zoom
3. Feature requests recorded in CRM
4. Internet: Reddit and Twitter
5. Confluence 
6. Github for feasibility

Email and Slack were deliberately left out, so the agent doesn't inherit the urgency sometimes attached to these ideas, and so it can act as an impartial research agent.

**How fresh must it be**

It should prioritize data from the past 12 months, but look at the big picture for the past 36 months. Tech is changing fast, but sometimes good ideas were there all along. If a source is unreachable, then it should flag that and stop research until that's fixed, because missing context is not acceptable.

## 02 Tools · System Capabilities

**The verb list**

The verb list:
- Jira/Confluence: read, draft
- Zoom: read
- CRM: read
- Internet (reddit, twitter): read
- Github: read
- Output file: read, draft, write, send

**Deliberate omissions**

For compliance reasons, the least amount of necessary access was given.

## 03 Loop · AI Costs & Latency

**Turn ceiling and escalation**

2 tries, than workaround

**Latency and cost target**

Target max 1 hour research time. Cost target: 8 USD per research. Use cost efficient context windows (create phases of research with outputs, and close chats after the output is produced) and optimize sub-agents by selecting task appropiate models.

## 04 Memory · Data Requirements

**What persists, at what scope**

Produce an .md file with all the information required to proceed. Discard chat context to save on context.

**Expiry and write rules**

Documents are created with clear timestamps. Therefore, context from existing research can be reused accordingly.

## 06 Verification · AI Testing & Measurement

**The check before output ships**

Validate customer status from CRM before adding it to the business case.

**Failure behaviour**

Flag that customer status was not verified during research.
